# 地図選択の簡素化と航空画像の改善調査

## 所有者依頼と範囲

2026-11-22の試用後、所有者はGoogle Mapsのような簡潔な地図選択と、レイヤーボタンのhoverによる展開を依頼。また衛星写真が粗いとして改善/代替を質問した。無料という従来条件を維持する。

今回の編集はUI・必要な回帰・仕様更新。元画像の10m級解像度はCSS/補間で高精細にできない。提供元変更・アカウント作成・利用規約への同意・課金・APIキー設定は、比較結果と所有者判断を分け、未承認のまま導入しない。現在の試用18280は維持し、独立worktreeで作業する。

## 実装計画

1. 4種類の小さな説明用プレビュー＋短いラベルを横並びにする。長い説明・通信情報・画質の限界・出典は開ける詳細へ移す。外部画像やGoogle素材をプレビューへ転載せず、CSSで描く。背景切替/保存処理/通信先は維持。
2. hover可能な細かいポインターではmouseenter相当で展開し、入口→選択肢へ移動する猶予を設ける。hoverでフォーカスやカメラを奪わず、閲覧だけで背景を切り替えない。
3. クリックは固定表示/終了、タッチはタップ、キーボードは入口から選択radioへ。×/Escape/余白で1層だけ閉じ、閉じた直後の自動再展開を防ぐ。選択肢や詳細へフォーカスがある間はmouseleaveで閉じない。
4. 1440/900/800/390/320、写真プレビュー・低画面・出典を確認。hover移動/離脱/固定/再展開抑制と、既存の選択・カメラ・検索・限定表示の保持を対象E2Eで確認する。
5. 公式資料で無料高精細の選択肢を比較。無料枠＋登録/キーと、キー不要の地域別高精細を区別する。公開URLへアクセスできることだけを利用許可の根拠にしない。

## 結果

UIを実装し、読み取りReviewerの確認を受けた。長いカードを4つの説明用プレビューと短名に置換し、詳細・通信情報・出典を折りたたみに集約した。Google素材・外部画像を追加せずCSSで描く。現在は衛星画像のみなので短名を「衛星写真」にした。

hoverは無選択・フォーカス不変、クリック固定、220ms離脱猶予、タッチ、Escape/×/余白を実装。低い画面でhoverパネルが入口を覆ってクリックできない問題を代表E2Eで検出し、空間がなければ入口の下へ配置するよう修正。閉じたパネルから下の入口が露出する際の再展開を抑制した。既存の左端だけの座標試験は、実際の非重複と選択肢のヒット判定へ更新した。

### 高画質な画像の比較（未採用）

所有者は追加質問に「アカウント・キー不要を優先する」と回答。現在のEOX2016約10m級の元情報は、maxzoom/補間/シャープ化だけで建物の詳細へ変えられない。世界全域・高精細・無料・アカウント/キー不要を同時に満たす、今回採用可能な正規配信は調査範囲で確認できなかった。

- [国土地理院の写真タイル](https://maps.gsi.go.jp/development/ichiran.html)：日本の航空写真。キー不要で、リアルタイムの表示は出典付きで利用可能。地域・資料時点による差がある。追加送信先は `cyberjapandata.gsi.go.jp`。日本の高精細と世界のEOXを併用する案は可能だが、今回は未採用。
- [USGS NAIP](https://imagery.nationalmap.gov/arcgis/rest/services/USGSNAIPImagery/ImageServer)：米国本土48州中心、主に0.6m級の公有航空画像。地域限定で、接続/CORS/実画質確認は追加採用時に必要。
- [ArcGIS Location Platform](https://location.arcgis.com/help/billing/)：世界画像の正規無料枠があるが、アカウント/認証が必要。新規PAYGは既定OFF、支払方法なしではON不可、無料枠超過時に対象サービス停止。所有者のキー不要優先により今回は採用しない。古いEsri公開タイルURLにアクセスできることだけを利用許可と見なさない。
- [MapTiler Free](https://www.maptiler.com/terms/cloud/)：アカウント/キーが必要、無料枠と利用用途の制約があるため今回未採用。

配信元変更・高画質化そのものは未実施。地域別の追加通信を承認後に別変更で実装できる。課金/登録/規約同意/キー保存はしていない。

### 検証

`npm run typecheck`、`npm run lint`、`npm run build`は成功（従来同様の500kB超chunk警告あり）。`PHOTO_ROUTE_TEST_PORT=18284`、`PHOTO_ROUTE_TEST_BROWSER=chromium`で対象地図10件＋代表onboarding1件、計11件が成功（43.8秒）。1440/390/320と800/900両側、320×568プレビューを画像で確認した。`python tools/check_specification.py`、`python tools/check_public_safety.py`、`git diff --check`も成功。公開候補441件、登録合成画像23件、既知秘密パターン0件。

初期失敗は、旧縦カードの横位置だけを期待する試験と、低画面で入口にhoverメニューが重なる問題。実ヒット判定へ更新し、パネルを入口の下に出す/隠れたパネル由来pointerleaveでは抑制を解除しない処理を追加した。skipやケース削除はない。UI変更なので単体全体の再実行・実配信タイルの大量再取得は省略（配信・背景合成・Domain・保存APIは変更なし）。実機タッチ/他ブラウザ/スクリーンリーダーは未確認。

新試用は18283番、元の18280番は起動したまま。保存領域は別。サムネイル模様はCSSのみで、新しい外部素材・依存・通信先・保存形式を追加しない。DB/ZIP/背景合成/保存処理を変えていないため、全移行・大量ZIP・全歴史的E2Eは今回実行しない。元の試用18280とmainは変更しない。
