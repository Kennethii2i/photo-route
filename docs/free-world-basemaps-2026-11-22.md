# 無料の世界対応背景地図4種類：計画と検証

## 依頼と範囲

所有者は2026-11-22の対話で、標準・航空/衛星写真・地形・淡色の4種類と、学術情報を「詳しく知る」へまとめる構成に賛成。その後「無料のもの」「基本地図4つを実装」「計画を立ててから実装」と明示依頼した。本変更は基本地図と左下の選択UIを対象とする。学術レイヤー、施設検索API、アカウント、課金、オフライン地図保存は対象外。

無料・APIキー不要・支払登録不要の公開配信を選び、選択した地図に必要な通信だけを追加する。写真・Exif・ファイル名・所属を送らず、閲覧タイル範囲/IP等が提供者へ伝わり得る説明を表示する。今回の無料世界地図追加を依頼の範囲とし、有料契約や他サービスへの自動代替は行わない。

## 配信計画

| 種類 | 候補 | 条件と制約 |
|---|---|---|
| 標準 | OpenFreeMap Liberty | 現在と同じ配信先。施設名は地図データ・縮尺に依存 |
| 淡色 | OpenFreeMap Positron | 現行表示を残す |
| 航空・衛星写真 | EOX cloudless **2016** | 2016版のみCC BY 4.0で無料公開配信・商用利用可。約10m級の古い衛星モザイク。建物単位の詳細/最新画像は保証しない。2018以降へ切り替えない |
| 地形 | Mapterhorn | 公開Terrarium標高タイルを2D陰影で表示。元資料の条件・地域ごとの精度差あり |

公式確認資料：

- [OpenFreeMap](https://openfreemap.org/quick_start/)
- [EOX公式FAQ：2016版・無料公開配信・Fair Use・無SLA](https://cloudless.eox.at/documentation/faq)
- [EOX WMTS定義](https://tiles.maps.eox.at/wmts/1.0.0/WMTSCapabilities.xml)
- [Mapterhorn配信](https://mapterhorn.com/data-access/) / [出典](https://mapterhorn.com/attribution/)

利用料がないことと稼働保証を区別する。大量取得/先読み/独自キャッシュは追加しない。配信停止時は選択名と失敗を表示し、再試行または既存地図への手動切替を可能にする。

## 実装順と受入条件

1. 公式の配信URL・ズーム・CORS・出典を確認して設定へ集約する。DB/ZIP/Domainモデル/依存を変更しない。
2. 背景切替を写真/アルバム表示設定から分離する。非同期切替の世代管理・中断・期限を持たせ、古い応答や再試行で別の背景へ戻さない。写真レイヤーを復元し、中心・ズーム・写真選択・検索・アルバム限定表示を維持。
3. PCはdrawerに追従する左下「レイヤー」と4択、モバイルは既存3タブを維持した選択パネル。44px・キーボード・Escape/×・フォーカス復帰・地図余白で1層終了・出典非遮蔽を確認する。衛星の年代/画質と追加通信先を選択UIに明記。
4. 世界対応の表示境界として日付変更線をまたぐfitを修正し、保存座標は変更しない。
5. 代表E2E・単体・型/Lint/build・文書/公開安全性検査を実施。PC1440/モバイル390/320で画像と操作領域を確認。外部実地図の検証とローカル模擬応答の検証を区別する。
6. 独立Reviewerへ読み取りレビューを依頼し、指摘修正後に結果・未確認・変更ファイルを報告。main統合/Push/公開は今回行わない。

レイヤー選択は当該ページの表示状態とし、新しい永続形式や選択の自動復元は追加しない。ロールバックは変更前コード/既存背景の使用へ戻すことで可能で、DB移行は不要。

- `npm run lint`：成功。
- `npm test`：22ファイル・125件成功（追加5件）。
- `npm run build`：成功。既存同様の500kB超chunk警告あり。依存追加/バンドル分割は今回対象外。
- `python tools/check_specification.py`、`python tools/check_public_safety.py`、`git diff --check`：成功。公開候補440件・合成画像23件・既知秘密パターン0件。秘密不存在の完全な証明ではない。
- 隔離Chromium、専用ポート18278、合成写真のみ。対象の4背景、カメラ/写真選択/検索/DBレコードとサムネイルバイト列不変、アルバム限定、連打/HTTP失敗/タイル503/未応答期限、キーボード/44px/出典、1440/390/320、800/900両側パネル、320×568プレビュー、日付変更線fit→写真選択を検証。代表onboardingを含む9件が最終成功（対象8件＋代表1件、32.1秒）。
