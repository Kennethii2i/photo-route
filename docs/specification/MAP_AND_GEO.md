## 背景地図と位置の根拠

MapLibre GL JSを使用し、既定スタイルは`https://tiles.openfreemap.org/styles/liberty`。現在は起動時に取得する実装です。旧資料の「地図OFFが既定、初回同意後だけ表示」は現行仕様ではありません。地図左下に背景選択、管理画面に写真/アルバム表示設定と配信元/プライバシー説明があります。地図タイル/スタイル/フォント/スプライトの外部通信を伴います。

GeoJSONは`[longitude, latitude]`、座標はWGS84を基準に表示します。`sourceGpsDisplay()`は保存済みrawTagsを再評価し、以下を区別します。

| 根拠 | 表示 |
|---|---|
| 手動GPS補正 | 手動のWGS84位置。元Exifとは別 |
| WGS84タグと有効座標、または検証済み旧normalized | 確認済み位置 |
| 測地系タグ不明だが有効なraw座標 | 表示時だけWGS84を仮定した参考位置。黄土色/参考ラベル |
| 明示的な非WGS84、不正値、位置なし | 地図点を作らない。自動変換しない |

水平誤差は測地系の確実性ではありません。参考位置を保存済みnormalizedへ書き戻さず、GPSなし写真にアルバム代表地点を割り当てません。

## マーカー・クラスタ

PhotoとVisitは別GeoJSONソース。Photoはズーム別にクラスタ化（`clusterRadius:40`, `clusterMaxZoom:16`）。通常の写真サムネイルは高ズーム時に取得し、画面上の同一座標を1つのサムネイル/枚数表示へまとめます。描画用取得は最大64地点、画像取得の同時数は4です。画像は固定クリップ領域内でcoverし、選択リング/件数は外側で保持します。

| 操作 | カメラと表示 |
|---|---|
| 写真一覧/単独写真マーカーを選択 | プレビューと選択を更新。ズーム維持。対象が可視領域外の場合だけパン |
| 同じ写真を再選択 | 選択/プレビュー解除。カメラを動かさない |
| クラスタを直接タップ | `getClusterExpansionZoom()`を使って拡大。写真選択とは別操作 |
| 写真の明示的な「地図で見る」 | `focusPhoto()`で周辺が見えるズーム15へ。最大ズームを位置合わせ目的に使わない |
| 全表示 / アルバム地図 | 既存の座標集合を可視領域へfit。これは明示操作 |

`revealPhoto()`は既存のDOM実寸を読む`mapViewportInsets()`を再利用します。PCの左右パネル、ヘッダー、モバイルの下部タブ/プレビュー、ズーム/出典表示等の障害物を避ける矩形を使い、最大40pxの余裕を確保。`panBy(duration:0)`だけを必要時に実行します。モバイルのResizeObserver反映を待って一度だけ判定し、drawer開閉/詳細終了/検索入力だけでパンを増やしません。

短時間の写真切替では、最後の選択ID/表示状態を再確認します。クラスタ強調の非同期照合はカメラを動かしません。現在描画されるクラスタの葉に写真IDがあることを確認できた場合だけ、控えめな輪郭を表示します。照合は合計1000葉までで、未確認/未ロード/世代不一致は推測せずプレビューだけを維持します。別の写真マーカーを追加しません。

## 同一地点の展開

最大ズーム等で分離しない写真は`showSpider()`で地図上へ一時展開します。ページ送りUIはありません。

- 2〜12枚の全矩形が入る場合は画面座標のoffsetで配置。7〜9枚は中心/外周、10〜12枚は内外リングを使用。
- ターゲットは48px、矩形間の目標間隔8px、可視領域端8pxを確保して半径/中心を調整。GPSやMarkerの元LngLatは変えない。
- 元の集合サムネイルは展開中のみ隠す。元位置の通常の点は連結線の起点として残る。移した中心への線は1本にまとめてから分岐。
- 写真を押すと通常プレビュー。余白/Escape、地図移動/ズーム/リサイズ等で一時展開/URLを解放。
- **13枚以上、または12枚以下でも領域不足**なら、既存の仮想写真一覧にその地点の全IDを一時表示。15枚以上を切り捨てず、一覧から全写真へ到達できる。新しい選択モーダルは作らない。

この一時一覧を閉じると通常の検索とスクロールへ戻ります。検索/所属リンク/アルバム限定状態を、一覧表示のために破壊的変更しません。

## アルバム限定地図

`startVisitFocus()`はリンクから得たアルバム所属写真の位置だけを地図に渡し、モバイルでは地図タブへ切り替えます。検索欄は保持し、限定モード終了時に通常の絞り込みとレイヤー状態へ戻します。開始時は所属GPS写真全体をfitします。空/GPSなしは「地図に表示できる写真がありません」で扱い、架空座標を作りません。

`visitFocusPhotoIds()`には外れ値を避ける表示集計もありますが、現行の開始処理は`focus.all`をfitします。関数の存在だけから「外れ値を必ず除外する」と説明しません。

## 出典・障害

OpenFreeMap/供給スタイル由来のMapLibre attributionを保持し、管理画面にも配信元説明があります。帰属を画像や操作で隠さない配置を維持します。一部タイルの一時失敗で通知を連発せず、背景内容が描けず複数失敗した場合等に案内します。再試行はスタイル再取得で、保存データの再送ではありません。

## 2026-11-22 無料の世界背景4種類

左下の「レイヤー」から標準（OpenFreeMap Liberty）・航空/衛星写真（EOX cloudless 2016）・地形（Mapterhornの2D陰影）・淡色（OpenFreeMap Positron）を選ぶ。標準が起動時の既定。選択はページ内だけの状態で、再読み込みでは標準へ戻る。追加配信は対象を選択したときだけ開始し、APIキー・支払登録・課金経路はない。

衛星画像は2016年の約10m級モザイクで、最新/建物単位の詳細画像ではない。元画像maxzoom14、標高は全球ベースmaxzoom12で過大な取得を避ける。上の縮尺へ拡大しても元画像の精細さは増えない。ラベルはOpenFreeMapの独立したsymbolレイヤーを使い、元データにない施設は補わない。高緯度の投影限界、無料配信の可用性、データの時点・地域差を保証しない。学術テーマ/施設検索APIは未実装。

背景切替は写真/アルバム表示切替と別経路。中心・ズーム・選択・検索・アルバム限定表示を保持し、style再構築後に写真/アルバムのソースを戻す。非同期スタイル取得は中断/世代管理/15秒期限を持ち、失敗は前表示を保持して要求した地図を再試行できる。画像タイル失敗はラベルが残っても通知する。別配信元への自動代替はしない。

日付変更線をまたぐfitでは最短の経度区間を選び、保存されたGPSを変更しない。実装: [配信設定](../../src/infrastructure/basemap.ts)、[4択UI](../../src/presentation/basemap-control.ts)、[表示境界](../../src/presentation/map-bounds.ts)。[計画と検証](../free-world-basemaps-2026-11-22.md)。
