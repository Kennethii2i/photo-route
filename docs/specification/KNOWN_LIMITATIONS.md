# 既知の制約・未確認事項

## 意図的に提供していない機能

| 項目 | 現状と根拠 |
|---|---|
| 元の高解像度写真保存/原本ビューア | メタデータとサムネイルのみ保存。[image](../../src/infrastructure/image.ts)/[importer](../../src/application/import-photos.ts)。原本再取得・全画面原本表示はない |
| 端末間同期/共有/認証 | クライアントとIndexedDBが基本。同期/アカウントのサーバーなし |
| 手動カバー保存/写真メモ | `coverPhotoId`/メモの保存フィールドなし。表示用に既存写真のサムネイルを選ぶことと永続的なカバー指定は別 |
| 旅行名変更/既存写真の旅行移動 | 現行の旅行管理は作成・選択・ごみ箱。Photo.tripId移動用UI/APIなし |
| 旅行横断アルバム | リンクは同一Tripに限定 |
| 旧代表地点/手動日時入力 | 保存フィールドは残るが通常UIから撤去。写真GPS/撮影期間/カバーへ変換しない |
| 一般Undo操作 | [内部API](../../src/infrastructure/storage.ts)と履歴は保持するが、通知/管理/ショートカットからの実行UIはない |
| 完全削除/上書き復元 | 一般UIになし。ごみ箱と追加型復元を使う |
| 自動分類/経路推定/自動GPS・時差補正 | 実装なし。地図上の展開連結線は旅行の実移動経路ではない |

## 動作上の制約

- HEIC/HEIFの安全なサムネイル復号は未対応。依存にHEICライブラリがあることを製品対応の証拠にしません。
- JPEG/PNG/WebPもブラウザの復号/向き適用に依存し、サムネイル生成に失敗すると部分成功になり得ます。原本を別途保管してください。
- IndexedDBは端末/ブラウザ/オリジンに依存し、永続保存の完全保証はありません。ZIP暗号化はなく、jobs/recovery/原本はZIP対象外。
- 取り込みは1枚ずつ部分保存。中断しても保存済み分は残り、ジョブ更新失敗時に保存状況の再確認が必要です。
- `markInterruptedJobs()`は定義済みですが、現行起動経路に呼び出しがなく、再起動後のrunning状態訂正/処理再開は保証しません。今回は文書化だけで修正していません。
- ドラフトはメモリー上で保持し、ページ再読み込み/ブラウザ強制終了を越えた永続復帰はありません。
- 所属保存の期待状態比較と、補正保存等の別APIを同じ競合契約だと考えません。各トランザクション/引数を確認してください。
- クラスタ強調は1000葉までの正確な照合で確認できた場合だけ。未確認でもプレビューは使えます。
- 画面に入らない展開や13枚以上は一覧へフォールバック。全写真を無理に地図へ並べません。
- ZIP上限は[保存仕様](STORAGE_AND_BACKUP.md)の暫定値。大量データのすべてのブラウザ/低メモリー端末で安全に扱える保証ではありません。

## 未確認

実機タッチ、ソフトキーボード、全OS/全ブラウザ、長時間利用後のメモリー、あらゆる不正画像への耐性、公開HTTPSでの実運用、GitHub Actions実行、GitHub Pagesの実復元/直接保存は未確認です。過去の隔離試験を一般環境の保証へ拡大しません。GitHub公開の判断事項は[公開前検査](PUBLICATION_REVIEW.md)に分けています。

## 過去資料との主な相違

| 初期/過去資料 | 現在のコード |
|---|---|
| React推奨の構成案 | 実装はTypeScript/DOM主体 |
| Phase 3状態、単一visitId所属、DB v2 | DB v3、リンク正本の多対多。旧visitIdは互換用で通常null |
| ZIP v1書き出し | v2出力とv1入力互換 |
| 背景地図は既定OFF/同意後だけ | 現行はOpenFreeMapを起動時に表示し、説明と設定を提供 |
| Undo通知/管理Undo | 一般Undo UI撤去。内部API/recovery/ごみ箱復元は維持 |
| 同一地点6枚のページ送り | 最大12枚の画面内展開、領域不足/多数は既存一覧 |
| 写真選択でズーム17以上へ | W1はズーム維持と必要パン。明示地図操作は15 |
| 写真追加が管理内/独立した大ボタン行 | 写真件数右のコンパクトな＋ |
| 写真削除が詳細編集の中 | 詳細の地図アイコン隣。未保存保護と写真本体確認 |
| 特定アルバム条件は将来案 | 現在の`renderLibrary`が同一旅行の候補を生成し、通常フィルターに接続 |
